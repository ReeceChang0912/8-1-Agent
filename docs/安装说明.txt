========================================
  家庭智能管家 - 安装和运行说明
========================================

📦 快速开始（3步）
========================================

1️⃣  安装依赖
   打开PowerShell或命令提示符，进入项目目录：
   
   cd E:\myAgent
   uv sync

2️⃣  运行测试（可选）
   
   python test_agent.py

3️⃣  启动Web界面
   
   streamlit run main.py

   浏览器会自动打开 http://localhost:8501


🎯 使用说明
========================================

首次使用：

1. 添加家庭成员
   - 点击左侧 "👨‍👩‍👧‍👦 家庭成员"
   - 填写信息并添加

2. 开始对话
   - 点击 "💬 智能对话"
   - 在输入框输入消息

3. 添加知识
   - 点击 "📚 知识库"
   - 选择 "添加文档" 标签
   - 输入标题和内容


🔧 常见问题
========================================

Q: 安装失败怎么办？
A: 确保已安装Python 3.13+和uv工具
   访问 https://github.com/astral-sh/uv 安装uv

Q: 如何停止服务？
A: 在命令行窗口按 Ctrl+C

Q: 数据存在哪里？
A: 所有数据在 data 文件夹，本地存储

Q: 可以手机访问吗？
A: 可以！手机和电脑在同一WiFi，访问 http://电脑IP:8501
