# 家庭智能管家 - 快速开始指南

## 📦 安装步骤

### 方法一：使用启动脚本（推荐）

双击运行 `run.bat`，自动完成安装、测试和启动。

### 方法二：手动安装

1. **安装依赖**
   ```bash
   uv sync
   ```

2. **运行测试**
   ```bash
   python test_agent.py
   ```

3. **启动Web界面**
   ```bash
   streamlit run main.py
   ```

4. **访问应用**
   
   浏览器打开：http://localhost:8501

## 🎯 使用教程

### 1. 添加家庭成员

首次使用，先添加家庭成员：

1. 点击左侧菜单 "👨‍👩‍👧‍👦 家庭成员"
2. 填写成员信息：
   - 姓名：如"爸爸"
   - 角色：选择"爸爸"、"妈妈"等
   - 年龄：输入年龄
   - 交互风格：
     - 平等交流：适合夫妻之间
     - 童趣模式：适合与孩子对话
     - 长辈模式：适合与老人对话
   - 权限等级：
     - 管理员：完全控制（建议夫妻使用）
     - 普通成员：可以添加日程等
     - 儿童：受限访问

3. 点击"添加成员"

### 2. 智能对话

1. 在左侧选择当前用户（可选）
2. 在对话框输入消息，例如：
   - "你好！"
   - "我今天有点担心孩子的学习"
   - "帮我设置一个生日提醒"
   - "高血压患者应该注意什么？"

3. 系统会：
   - 自动检测情绪
   - 如果是负面情绪，会先安抚
   - 检索相关记忆和知识
   - 给出个性化回复

### 3. 添加知识库内容

让Agent更懂你的家庭：

1. 点击 "📚 知识库"
2. 选择 "添加文档" 标签
3. 输入：
   - 标题：如"家庭用药清单"
   - 内容：详细文本
   - 分类：选择合适分类（health/finance/education等）
4. 点击"添加到知识库"

之后可以搜索这些知识。

### 4. 设置提醒

1. 点击 "📅 日程管理"
2. 输入事件标题和日期时间
3. 点击"设置提醒"

- 切换到"小明"（童趣模式）：语言更简单、有趣

## 🔧 常见问题

### Q: 如何重置所有数据？

A: 删除 `data` 文件夹，重新启动即可。

### Q: 支持哪些文档格式？

A: 目前支持 TXT、PDF。其他格式正在开发中。

### Q: 数据存在哪里？

A: 所有数据存储在本地 `data` 文件夹，不会上传到云端。

### Q: 如何备份数据？

A: 直接复制整个 `data` 文件夹到其他位置即可。

### Q: 可以用手机访问吗？

A: 可以！确保手机和电脑在同一局域网，访问 `http://电脑IP:8501`

## 🚀 进阶用法

### Python API调用

```python
from family_agent.core import FamilyAgentCore
from family_agent.role_manager import FamilyMember

# 创建Agent
agent = FamilyAgentCore()

# 添加成员
member = FamilyMember(
    name="爸爸",
    role="父亲",
    age=45,
    side="core"
)
agent.add_member(member)

# 对话
response = agent.chat("你好！", user_id="爸爸")
print(response)

# 添加知识
agent.knowledge_base.add_text(
    text="重要信息...",
    title="标题",
    category="general"
)

# 搜索
results = agent.knowledge_base.search("关键词")
```
